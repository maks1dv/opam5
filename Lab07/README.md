## Завдання 3 · Агрегація (`Aggregate<T, TAcc>`)
Параметр варіанта **c = 3** (мінімум). Усі чотири обчислення виконано одним методом `Aggregate` без написання додаткових циклів:

1. **Сума**
   - **Стан:** поточна накопичена сума (`int acc`)
   - **Старт:** `0`
   - **Крок:** `(acc, x) => acc + x`

2. **Добуток**
   - **Стан:** поточний накопичений добуток (`long acc`)
   - **Старт:** `1L`
   - **Крок:** `(acc, x) => acc * x`

3. **Максимум**
   - **Стан:** найбільший знайдений елемент (`int acc`)
   - **Старт:** `int.MinValue`
   - **Крок:** `(acc, x) => x > acc ? x : acc`

4. **Мінімум (`c = 3`)**
   - **Стан:** найменший знайдений елемент (`int acc`)
   - **Старт:** `int.MaxValue`
   - **Крок:** `(acc, x) => x < acc ? x : acc`
