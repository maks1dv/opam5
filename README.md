# Лабораторна робота №5: Алгоритми на стеку та черзі

## Завдання 1 · Стек: Збалансованість дужок
**Параметр $a = 2$:** Перевірка дужок `()`, `[]`, `{}` (дужки в лапках `"..."` ігноруються).

### Результати обов'язкових тестів:
| Рядок | Очікувано | Отримано | Індекс помилки |
|---|---|---|---|
| `"(a[b]{c})"` | Збалансований | Збалансований | `-1` |
| `"([)]"` | Незбалансований | Незбалансований | `2` |
| `")("` | Незбалансований | Незбалансований | `0` |
| `"(("` | Незбалансований | Незбалансований | `2` |
| `""` | Збалансований | Збалансований | `-1` |

* **Спеціальний тест ($17$ відкривальних, $16$ закривальних):** `((((((((((((((((()))))))))))))))))`
* **Результат:** Незбалансований, індекс помилки: `33`.

## Завдання 2 · Стек: Зворотний польський запис (RPN)
**Параметр $b = 0$:** Операції `+`, `-`, `*`, `/`.

### Результати обов'язкових тестів:
| Вираз | Очікувано | Отримано | Статус |
|---|---|---|---|
| `"3 4 + 2 *"` | `14` | `14` | Успішно |
| `"5 3 -"` | `2` | `2` | Успішно |
| `"8 2 /"` | `4` | `4` | Успішно |
| `"2 3 4 * +"` | `14` | `14` | Успішно |
| `"5 0 /"` | Помилка | `0` | Помилка: ділення на нуль. |

* **Власний вираз ($K = 17$):** `"10 5 + 4 2 / +"` $\rightarrow (10 + 5) + (4 / 2) = 17$.

## Завдання 5 · Обґрунтування

1. **Завдання 1 (Дужки):** Потрібен **стек (LIFO)**, бо остання відкрита дужка має закриватися першою. У черзі (FIFO) перевірка вкладеності зламалася б.
2. **Завдання 2 (RPN):** Потрібен **стек (LIFO)** для доступу до двох найостанніших операндів. У черзі змінився б порядок аргументів для некомутативних операцій (наприклад, $3 - 5$ замість $5 - 3$).
3. **Завдання 3 (Обслуговування):** Потрібна **черга (FIFO)** для дотримання хронологічного порядку приходу заявок. Стек призвів би до "голодування" (starvation) перших заявок.
4. **`Queue.Dequeue()` vs `List.RemoveAt(0)`:** `Dequeue()` виконується за **$O(1)$** (зсув вказівника в кільцевому буфері), а `RemoveAt(0)` за **$O(N)$** (зсув усіх елементів у пам'яті). Згідно з замірами ЛР4: **1.2 мс** проти **420 мс** на 100 тис. елементів.
